# Матрица ролей и прав доступа (RBAC Matrix)

В Google Classroom реализована строгая ролевая модель для образовательных учреждений. Ниже приведена матрица прав доступа, адаптированная для системы **BormoClass**.

---

## 1. Роли пользователей

1. **Главный преподаватель (Primary Teacher / Course Owner):**
   - Создатель курса или преподаватель, которому передали право владения.
   - Имеет полные права на управление курсом, включая удаление курса и передачу владения.
2. **Преподаватель-соавтор (Co-Teacher):**
   - Приглашённый коллега с равными правами преподавания.
   - Может создавать и проверять задания, выставлять оценки, публиковать объявления.
   - Не может удалить курс или удалить главного преподавателя.
3. **Ученик (Student):**
   - Участник учебного процесса.
   - Просматривает материалы, прикрепляет решения, сдаёт задания, видит свои оценки.
   - Не видит чужие решения и оценки других учеников.
4. **Опекун / Родитель (Guardian):**
   - Привязан к конкретному ученику.
   - Получает сводки о сданных, пропущенных и предстоящих работах подопечного.
   - Не имеет прямого доступа к материалам и закрытым обсуждениям курса.
5. **Администратор школы / системы (Domain Admin):**
   - Управление каталогом курсов всей школы/организации, назначение преподавателей, аудит.

---

## 2. Сводная матрица разрешений (RBAC Matrix)

| Действие / Операция | Главный учитель (Owner) | Со-преподаватель (Co-Teacher) | Ученик (Student) | Родитель (Guardian) | Администратор |
|---|:---:|:---:|:---:|:---:|:---:|
| **Управление курсом** |
| Создание нового курса |  Да |  Да | ❌ Нет | ❌ Нет |  Да |
| Изменение названия, описания, аудитории |  Да |  Да | ❌ Нет | ❌ Нет |  Да |
| Архивирование / разархивирование |  Да |  Да | ❌ Нет | ❌ Нет |  Да |
| Полное удаление курса |  Да | ❌ Нет | ❌ Нет | ❌ Нет |  Да |
| Передача владения курсом другому учителю |  Да | ❌ Нет | ❌ Нет | ❌ Нет |  Да |
| Включение / сброс кода курса (`enrollmentCode`) |  Да |  Да | ❌ Нет | ❌ Нет |  Да |
| **Участники курса** |
| Приглашение / добавление учителей |  Да |  Да | ❌ Нет | ❌ Нет |  Да |
| Удаление со-преподавателя |  Да | ❌ Нет* | ❌ Нет | ❌ Нет |  Да |
| Приглашение / зачисление учеников |  Да |  Да | ❌ Нет | ❌ Нет |  Да |
| Исключение ученика из курса |  Да |  Да | ❌ Нет | ❌ Нет |  Да |
| Самостоятельный выход из курса | ❌ (Только архив/передача) |  Да |  Да | ❌ Нет | — |
| Приглашение опекунов ученика |  Да |  Да | ❌ Нет | ❌ Нет |  Да |
| **Учебные задания и темы (CourseWork & Topics)** |
| Создание / редактирование тем (`Topic`) |  Да |  Да | ❌ Нет | ❌ Нет |  Да |
| Публикация заданий (`CourseWork`) |  Да |  Да | ❌ Нет | ❌ Нет |  Да |
| Создание черновиков и отложенных заданий |  Да |  Да | ❌ Нет | ❌ Нет |  Да |
| Прикрепление рубрики оценивания (`Rubric`) |  Да |  Да | ❌ Нет | ❌ Нет |  Да |
| Просмотр заданий |  Да |  Да |  Да (назначенных) |  Да (сводка) |  Да |
| Удаление заданий |  Да |  Да | ❌ Нет | ❌ Нет |  Да |
| **Сдача работ (Submissions)** |
| Прикрепление решений (файлы, ссылки, доски) | ❌ Нет | ❌ Нет |  Да (до сдачи) | ❌ Нет | ❌ Нет |
| Нажатие «Сдать» (`turnIn`) | ❌ Нет | ❌ Нет |  Да | ❌ Нет | ❌ Нет |
| Отмена отправки (`reclaim`) | ❌ Нет | ❌ Нет |  Да | ❌ Нет | ❌ Нет |
| Просмотр решений всех учеников |  Да |  Да | ❌ Нет | ❌ Нет |  Да |
| Просмотр собственного решения | — | — |  Да |  Да |  Да |
| **Оценивание (Grading)** |
| Выставление черновой оценки (`draftGrade`) |  Да |  Да | ❌ Нет | ❌ Нет |  Да |
| Возврат работы ученику с оценкой (`return`) |  Да |  Да | ❌ Нет | ❌ Нет |  Да |
| Просмотр журнала оценок всего класса |  Да |  Да | ❌ Нет | ❌ Нет |  Да |
| Просмотр своих личных оценок | ❌ Нет | ❌ Нет |  Да |  Да (сводка) |  Да |
| **Коммуникация (Лента / Объявления / Комментарии)** |
| Публикация объявления в ленту |  Да |  Да | Опционально** | ❌ Нет |  Да |
| Публикация публичных комментариев |  Да |  Да | Опционально** | ❌ Нет |  Да |
| Удаление чужих комментариев |  Да |  Да | ❌ Нет | ❌ Нет |  Да |
| Приватные комментарии к сдаче (1 на 1) |  Да |  Да |  Да (только со своим учителем) | ❌ Нет |  Да |

*\* Со-преподаватель может удалить только сам себя из курса.*  
*\*\* В настройках курса преподаватель может настроить режим для учеников: «Ученики могут публиковать и комментировать», «Ученики могут только комментировать» или «Только преподаватели могут публиковать и комментировать».*
